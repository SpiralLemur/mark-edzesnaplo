Mark Edzésnapló V6.4

Újdonságok:
- SET 3/3 lejáratakor a gyakorlat automatikusan kipipálódik.
- A Hétfő, Szerda és Péntek edzésoldal alján START WORKOUT indítja az edzés stoppert.
- A STOP WORKOUT megnyomásakor a program megkérdezi: „Mentsem?”
- Igen esetén elmenti az edzést és az eltelt időt az előzményekbe.
- Mégsem esetén nem menti az edzést, és nullázza a stoppert.
- A V6.3 edzésterv, sötét mód, SET-számláló és pihenőhang megmaradt.
